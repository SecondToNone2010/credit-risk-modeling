# Data

The project is written for the UCI **Default of Credit Card Clients** file. Raw data is not committed here.

For a cleaned CSV, the main fields expected by the script are:

- `limit_balance`
- `pay_status_1` ... `pay_status_6`
- `bill_amount_1` ... `bill_amount_6`
- `payment_amount_1` ... `payment_amount_6`
- `default_next_month`

The original UCI Excel names are renamed automatically.
